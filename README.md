# Arctri website

Landing page for [Arctri](https://github.com/7sadakonr/Arctri). Vue 3 + Vite + Tailwind CSS 4, EN/TH.

```
npm install
npm run dev      # local dev server
npm run build    # type-check + production build → dist/
```

Download buttons read the latest GitHub release (`src/config.ts`). Until a release with a `.exe` / `.dmg` asset exists, they link to the Releases page. Deploy `dist/` to Vercel or any static host.
